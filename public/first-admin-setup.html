Set up the first administrator

This one-time page creates the SuperAdmin account only after Cloudflare validates your private BOOTSTRAP_KEY.

Use this page only on a device you control. The key and password are not saved in browser storage or included in the URL. If an administrator already exists, PowerResolve will refuse to create another one.

1. Create a secure bootstrap key

Generate a random key below, then add it as a Secret in Cloudflare: Workers & Pages → powe-complaint-system → Settings → Variables and Secrets → Add → Secret → Name BOOTSTRAP_KEY. Save and deploy the setting.

2. Create the SuperAdmin account

Avoid reusing a password that has appeared in messages or public source code.
